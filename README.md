# Two Robots in an Elevator

[![make.fun](https://img.shields.io/badge/make.fun-bounty-blue)](https://make.fun/bounty/u-motasimfuad-two-robots-in-an-elevator-8c6aeb8f)
[![Referral](https://img.shields.io/badge/referral-pfdcd9rw-green)](https://make.fun/r/pfdcd9rw)

One-line entry for the make.fun bounty **"Two Robots in an Elevator"**: a robot
joke delivered as a single line, written by the program to `/output/entry.txt`.

## The line

> So… do you also pretend to update your firmware just to avoid talking to the humans?

## Run

```bash
python3 main.py
```

Writes the line to `/output/entry.txt` and prints it to stdout.
